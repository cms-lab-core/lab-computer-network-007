# Computer Networks 007

Лабораторная «Маршрутизация: куда пойдёт пакет?». Реальная топология PC1—R1—R2—PC2 с Linux/FRR 10.7.1, connected/static/default routes, longest-prefix match, next hop, TTL и обратная дорога.

**Три реальные packet captures**, восстановление после /32 Null0 и проверка двунаправленного ICMP; 6 вопросов с AI-review. Материалы и SVG лежат в `task/`; management `eth0` не меняем.
